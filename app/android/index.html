How to allow installing the APK

Android blocks apps from outside Google Play by default. To install the 1xBet APK you allow it once for your browser, then switch it back off.

  1. Open Settings → Apps (or Security).
  2. Find Special app access → Install unknown apps.
  3. Choose the browser you used to download the file and turn on Allow from this source.
  4. After installing, come back and turn it off again.

Menu names differ a little between phone brands such as Samsung, Tecno, Infinix and Xiaomi.
