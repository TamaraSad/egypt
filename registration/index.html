1xBet registration problems and how to fix them

SMS code not arriving

Check the number and the +234 prefix, wait a minute and request a new code. If it still doesn’t come, try email registration and add your phone later.

“Phone number already registered”

You may already have an account. Use “Forgot password” to get back in instead of opening a second account — duplicates can be blocked.

Promo code not accepted

Copy the code without spaces and enter it before you tap “Register”. A code can’t be added to an account that already exists.

Lost one-click login details

If you add your phone or email to the profile, you can reset the password. Without them, contact 1xBet support from the site.

Wrong currency selected

Currency can’t be changed. Contact support before you deposit — they can advise on closing the account and opening a new one.

Verification rejected

Usually the photo is blurry or the details don’t match. Fix your profile details and upload a clearer photo of the same document.
